Implementing LATENESS / bounded-history trace GC — the biggest roadmap item ([P1] in docs/skipped.md), unblocked by the spine work ([[spine-sql-integration]]). It's the most cross-cutting feature: the core mechanism (a data-derived frontier; trace GC) is net-new (the runtime had only `TickCount`, traces had only `Current`+`Integrate`, INTERVAL is entirely absent).

**Model:** a column declared `LATENESS d` promises no future row has `c < max_seen − d`; the engine advertises `frontier = max_seen − d` (monotone); stateful ops keyed on `c` drop trace state with key `< frontier` (GC reduces *state*, never *output* — the group's last-emitted aggregate stays downstream). Late rows (below frontier) are dropped at the input (Feldera policy).

**Settled design decisions (from extended discussion):**
- First-class internal **Duration** (value+unit), NOT full SQL INTERVAL. INTERVAL's value-type + calendar semantics + connector I/O are deferred; calendar intervals are actually *wrong* for lateness (ambiguous frontier). Lateness bound never crosses a connector — it's a DDL constant.
- **Generic Int64 frontier core.** Temporal types are record structs over Int64 (`Timestamp`/`Time64` micros, `Date32` days), all `IComparable` (so `StructuralRowComparer` already orders them). Frontier math is Int64 either way.
- **`Timestamp[micros]` is the headline carrier; `BIGINT`/`Date32` come free** (thin extraction adapter). BIGINT = bring-up shortcut.
- Bound written as plain integer in native units; **defer duration-literal sugar** (`'1' HOUR`).
- **Mechanism vs policy seam:** frontier+retain-keys+late-drop are reach-independent; a separate monotonicity-annotation pass decides which ops GC. The DEFERRED **reach question** (minimal retain-keys vs full monotonicity propagation) plugs in ONLY at Phase 3's analysis pass. Working assumption: minimal reach.

**Phases:** 1 = frontier+retain-keys mechanism in Core (no SQL); 2 = input-side frontier source + late-drop + persist max_seen; 3 = SQL surface (parse LATENESS, schema/plan, minimal monotonicity pass, compiler wiring) — *reach decision lands here*; 4 = more operators + persistence + oracle/PBT; 5 = docs.
